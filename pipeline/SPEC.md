# The pipeline

Triggered by the phrase **"run the daily pipeline"**. The name is historical —
the cadence is monthly, producing two videos per run. Renaming it is optional;
the trigger phrase is already in muscle memory and documented in Notion.

## What one run produces

Two complete video packages. A package is done when it has:

1. A confirmed topic and its audience job
2. A full script
3. A title and thumbnail direction
4. A row in Notion with all of the above attached

## Provisional run order

Based on the installed skills, pending replacement by the real 9 roles.

| Step | Role | Output | Runs |
|------|------|--------|------|
| 1 | Idea scout | Candidate topics with live demand data | Per run |
| 2 | Competitor scan | Outliers and gaps in the niche | Quarterly, not per run |
| 3 | Topic select | 2 topics chosen against the slate and audience jobs | Per run |
| 4 | Script | Full script per topic | Per run, ×2 |
| 5 | Packaging | Title and thumbnail direction per topic | Per run, ×2 |
| 6 | Notion write | Rows created with script and packaging attached | Per run |

Brand kit and personal brand blueprint are set-up-once, not pipeline steps.

For videos 01–04 the slate in `CLAUDE.md` already fixes the topics, so steps 1–3
are skipped. Idea scouting starts to matter at video 05.

## The Notion gap

`Faceless Content Bank` has: Idea, Job, Notes, Status, Territory.

A produced video needs somewhere to put: Script, Title, Thumbnail direction,
Publish date, Video number, YouTube URL, Batch.

Two options, decision pending:

- **Extend the Content Bank** with the missing fields. One database, ideas and
  production in the same place. Simpler; the table gets wide.
- **Add a Video Production database** alongside it, related to the Content Bank.
  Ideas stay a scratchpad and graduate into production rows. Cleaner separation;
  one more thing to maintain.

Recommendation: extend the Content Bank. At two videos a month, a second
database is overhead before it is structure.
